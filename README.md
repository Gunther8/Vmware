# VMware Operations Resource Library | VMware 运维资源库

A repository for archiving commonly used resources in daily VMware data center operations, including ISO image links, automation scripts, practical tips, and related documentation. Continuously updated!

本仓库用于归档日常 VMware 数据中心运维过程中常用的 ISO 镜像、产品密钥、自动化脚本、实用技巧及相关文档资料。方便自用及团队共享，持续更新！

## Directory Structure | 目录结构

- [ISO/](./ISO)
  Download links and checksum notes for common VMware-related images.
  常用 VMware 相关镜像的下载链接与校验说明。

- [docs/](./docs)
  Operation manuals, configuration procedures, troubleshooting guides, and experience documents.
  操作手册、配置流程、故障排查、经验文档等。

- [scripts/](./scripts)
  Automation scripts including Python, Shell, and PowerShell for daily batch operations.
  自动化脚本，包含 Python、Shell、PowerShell 各类日常批量运维脚本。
    - [python/](./scripts/python)
    - [shell/](./scripts/shell)
    - [powershell/](./scripts/powershell)

- [tools/](./tools)
  Various third-party and custom tools with usage documentation.
  各类运维实用第三方或者自制工具及使用说明。

## Usage Notes | 使用说明

1. ISO files are large — only checksums (MD5/SHA1) and download links are stored here, not the actual ISOs.
   镜像文件较大，只有校验文件（如MD5/SHA1）和下载链接，不直接存放 ISO。
2. Product keys are for internal testing and learning only — do not leak them.
   产品密钥请注意安全，仅用于内部测试和学习用途，勿泄漏。
3. Contributions of scripts, workflows, tips, and documents are welcome.
   欢迎补充日常用到的脚本、流程、技巧和文档。
4. Use the Issue section for questions and discussions.
   有任何问题可通过 Issue 区反馈和讨论。
