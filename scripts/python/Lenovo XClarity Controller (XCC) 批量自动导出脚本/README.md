# Lenovo XClarity Controller (XCC) 批量自动导出脚本

本项目是针对 Lenovo XClarity Controller (BMC) Web 管理后台的自动导出数据脚本。脚本基于 Selenium 实现，可自动批量登录多台服务器，导出健康/资产/告警等数据为 Excel 文件，并按服务器 IP 自动归档，运行日志统一保存。

## 兼容性说明

* **支持 BMC 7.x 和 8.x 版本的 XClarity/XCC 管理后台**（如 7.00、7.20、8.60、8.82 等），只要 Web 页面有“导出Excel”按钮，均可自动化批量导出。
* **不支持 BMC 9.x 及以上新版本**（如 9.87），新版后台已取消 Excel 导出，仅能导出日志文件（LOG），本脚本暂不适配。
* 如遇页面按钮ID变化，可能需微调页面元素选择器（大多数 7.x/8.x 通用）。

> ⚠️ **安全提示：**
> 请勿在公开环境中披露生产服务器的真实 IP、账号密码或具体固件版本号。

## 功能特点

* 支持从 Excel 批量读取服务器列表
* 自动登录、批量导出、自动解压和归档
* 下载文件按服务器 IP 分类存储
* 全过程运行日志统一存放于 `log` 文件夹，日志文件含服务器IP和时间戳
* 支持实时日志输出与日志文件同步

## 使用方法

### 1. 准备环境

* Python 3.7 及以上
* 安装依赖库（`selenium`, `pandas`, `openpyxl` 等）

  ```bash
  pip install selenium pandas openpyxl
  ```
* 已安装 Chrome 浏览器及匹配版本的 ChromeDriver

### 2. 服务器列表文件

在项目根目录下新建 `server_list.xlsx`，**示例结构如下**：

| IP            | USERNAME | PASSWORD |
| ------------- | -------- | -------- |
| 192.168.1.100 | user1    | 123456   |
| 192.168.1.101 | admin    | abcdef   |

* 首行为表头
* 一行一台服务器，三列分别为：IP、用户名、密码

### 3. 运行脚本

```bash
python XCC2Excel.py
```

### 4. 查看结果

* **下载内容**：每台服务器的导出文件会存放在以其 IP 命名的文件夹下（如 `192.168.1.100/`）
* **日志文件**：所有运行日志自动保存在 `log` 文件夹下，每台服务器单独一个日志文件（含时间戳）

## 常见问题与注意事项

* 仅适用于 **7.x 和 8.x BMC（XCC/XClarity Controller）**，9.x 及更高版本不支持导出 Excel！
* 如导出失败，请手动登录 BMC 后台确认是否有“导出为 Excel”按钮。
* 服务器信息文件仅作脚本本地使用，请妥善保存，避免泄漏。
* 若需支持其它导出格式或页面变动，可自行扩展开发。
