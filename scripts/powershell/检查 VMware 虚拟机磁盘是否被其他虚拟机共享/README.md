# VMware 虚拟机磁盘共享检测脚本（PowerCLI）

本脚本用于 vSphere 环境中检查指定虚拟机的磁盘是否被其他虚拟机共享使用，辅助判断该虚拟机及磁盘是否可以安全删除。

## ✅ 功能说明

- 连接 vCenter Server
- 获取指定虚拟机的所有 VMDK 磁盘文件路径
- 遍历所有虚拟机，查找是否存在共享使用同一磁盘的情况
- 输出判断是否可以安全删除该虚拟机

## 🔧 使用方法

1. 安装 [VMware PowerCLI](https://developer.vmware.com/powercli/)
2. 修改脚本中的 vCenter 登录信息（服务器、账号、密码）
3. 修改目标虚拟机名称为你要检查的虚拟机
4. 在 PowerShell 中执行 `.ps1` 脚本，查看控制台输出

## 🔒 安全说明

- 本脚本只执行只读操作，不会对任何虚拟机、磁盘或集群配置产生影响
- 可放心在生产环境中使用

## 📦 输出示例

```
[检查磁盘] [666] 666.vmdk
该磁盘未被其他虚拟机使用。

✅ 所有磁盘仅属于虚拟机 VMname，可以安全删除。
```

## 🧩 适用环境

- vCenter 环境（ESXi 6.5及以上）
- PowerCLI 12.x 或 13.x
