# scripts Directory | scripts 目录说明

This directory collects and archives various automation scripts for VMware and data center operations.

本目录用于收集和归档各类 VMware 及数据中心运维相关的自动化脚本。

## Script Types | 脚本类型

- **Python**
  For API automation, batch operations, report generation, and more.
  用于接口自动化、批量操作、报表生成等场景。

- **Shell**
  For daily Linux/Unix operations, scheduled tasks, and system health checks.
  适合 Linux/Unix 系统下的日常运维、定时任务、系统检测等。

- **PowerShell**
  For Windows systems and vSphere PowerCLI automation.
  针对 Windows 系统和 vSphere PowerCLI 等环境的自动化操作。
