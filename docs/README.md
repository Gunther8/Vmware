# docs Directory | docs 目录说明

This directory archives operation manuals, configuration procedures, troubleshooting guides, experience summaries, tips, FAQs, and other documentation from daily operations.

本目录用于归档日常运维中的操作手册、配置流程、故障排查、经验总结、常用技巧、FAQ 等各类文档资料。

## Recommended Categories | 推荐分类

- Operation Manuals | 操作手册
- Configuration Procedures | 配置流程
- Troubleshooting | 故障排查
- Experience Summaries | 经验总结
- Tips & FAQs | 常用技巧与FAQ
- Pitfall Records | 踩坑记录
